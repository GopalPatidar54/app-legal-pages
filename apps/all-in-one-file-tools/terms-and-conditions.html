2. Description of the Service & On-Device Operation

All-in-One File Tools provides file utilities, including:

  • Image Compression (JPEG, PNG, WebP)
  • Video Compression (MP4, MOV, hardware-accelerated transcoding)
  • Image to PDF Generation
  • PDF to Image Extraction
  • PDF Compression & Optimization
  • PDF Merging and PDF Page Splitting

Local Processing: All processing operations occur directly on your local device hardware using device codecs and libraries. The App does not upload your media to remote servers for compression or conversion. Google AdMob may separately use advertising-related device data as described in the Privacy Policy.

Save Modes & Replace Original Caution

The App offers two save modes:

  • Create new file: Preserves your original and writes a new processed file (for example under AllInOne gallery folders).
  • Replace original file: Overwrites or replaces the source media in place when you explicitly choose this option and grant any required system write permission.

While the App aims to preserve authentic capture metadata (such as Date Taken, GPS, and camera/EXIF tags where available), device or system failures can still occur. You are responsible for keeping independent backups of irreplaceable photos and videos before using Replace original file.
